Lime Scooter Unlocker

Talks straight to the vehicle's Bluetooth UART. No Lime servers, no account, no install. For hardware you own.

Stock firmware drops BLE commands until it authenticates you. The password is the vehicle's IMEI. The 8 hex chars in the Bluetooth name are the last 4 bytes of DES(IMEI, 0x1122334455667788), so type the first digits of the IMEI and let it solve the rest. Runs in parallel workers off the main thread, so the page stays responsive and you can cancel.
